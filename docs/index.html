Why the score 0.1563 kept repeating

Same bytes

GEMSDOE1 and 5GEMSDOE host the byte-identical file (Git blob 812e61b740…). 8GEMSDOE differs only on known-fault pixels, which the evaluator masks, so it is the same submission. GEMSDOE2 overlaps it 94.6 %.

Copied seed

That same file sits at 8 paths in 6 repositories: each new repo was seeded from earlier evidence folders whose default submission.tif is the old winner.

Repeated idea

Three repos tried near-catalogue top-k predictions and all scored ≤ 0.046. The Results page has the matrix.
