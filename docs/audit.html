F01medium
open		Band 6 tc is mislabelled in the file's own tags
The GeoTIFF tags say tc = 'Tilt angle or total curvature - magnetic field derivative' (data_category magnetic_data). Numerically it correlates r = +0.997 with the external USGS GeoDAWN radiometric TOTAL COUNT channel and r = +0.013 with a computed magnetic tilt angle; all values are positive (2.95 to 88.6) while a tilt angle spans both signs. The DrivenData page figure caption also calls it total radiometric counts.		Treat tc as radiometric total count (surface lithology/soil), not a magnetic edge detector. Earlier hypotheses that assumed a magnetic meaning were mis-specified (numerically harmless, conceptually wrong).

F12low
open		GeoDAWN magnetic products have anisotropic resolution
Area 2 (most of the extent) was flown with 400 m east-west lines. Cross-line (north-south) sampling is coarse, so E-W lineaments in 100 m magnetic derivatives may be flight-line or levelling artefacts (inference, untested).		Down-weight purely E-W magnetic lineaments unless corroborated by topography.

F13high
open		'Predicted values must be in range [0, 1]' cannot be reproduced from any file in this repository
Every file ever published on this site (including the ZIPs and the versions from PR #1) passes all check variants: float32, finite 0-1 on every footprint pixel, correct grid. The repositories behind scored group entries publish files in every encoding (LZW/deflate, predictor 1/3, striped/tiled, NaN or zero outside), so the container is unlikely to be the cause (assuming the published file is what was uploaded). The likeliest causes are NaN or out-of-range values in a file from elsewhere, or server behaviour we cannot see.		Run the suspect file through the checker on the Submit page; if it passes but is rejected, email info@drivendata.org with the filename, SHA-256 and a screenshot.

F17medium
open		The holdout measures known faults; the real task scores NEW faults
Known faults are masked in the real scoring, so the dense proxy rewards something the evaluator ignores, and both proxies' hidden faults are Quaternary catalogue faults. Measured: across the group's 15 distinct scored files the dense known-fault DTI has Spearman rho +0.17 (p = 0.54) with the public score, and the SGMC-gap truth +0.52 (p = 0.048); neither is a dependable gate.		Treat holdout numbers as weak evidence; use the first live A/B pair to recalibrate (decision rules in the register, section 6b).
